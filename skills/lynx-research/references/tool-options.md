# 按需选择 GitHub 工具

- [MarkItDown](https://github.com/microsoft/markitdown)：从 Office/PDF 取文字为 Markdown，提取不保留原页面视觉，也不是 PPT 生成器。扫描件另用 OCR。
- [pdfplumber](https://github.com/jsvine/pdfplumber)：可选的本地 PDF 文本/表格提取，机器生成 PDF 较合适，扫描件没有 OCR。
- [PaddleOCR](https://github.com/PaddlePaddle/PaddleOCR)：中文扫描/图片 OCR，需下载依赖/模型；管理员准备环境，关键数字仍须复核。
- [Tavily skills](https://github.com/tavily-ai/skills)：搜索/提取支持有额度限制的免密模式；research/map/crawl 需要认证与配置。外部搜索将查询传给服务，不把客户保密内容当搜索词。
- [GPT Researcher](https://github.com/assafelovic/gpt-researcher)：管理员可部署的多来源研究服务，典型配置需要模型/搜索账号。未完成部署或验证时，只列为可选方案。

上游检查日期 2026-10-10。费用、配额和模型服务按实际账号核对；不提供未经验证的费用承诺。不从网页直接复制并执行安装脚本。
