# 保留意思，让文字更清楚

阅读 [编辑方法](references/editing-method.md)。改编自 Humanizer，来源与 MIT 许可见 [改编记录](THIRD_PARTY_NOTICES.md)。

1. 确认读者、用途、期望长度与口吻；有作者样稿就先读样稿。用户只要求改某段时不要重写整篇。
2. 标记空洞开场、重复总结、机械排比、无对象的夸张判断、过多标签/加粗、冗长铺垫和不必要术语；围绕每段的主意思修改，保留合理的对比和作者风格。
3. 对事实、数字、名称、日期、引用、程度与条件建立对照。不得为“更具体”而加案例、排名、效果或引用；不把“可能”改成“必然”，不把“计划”改成“已完成”。
4. 调整句长和段落，先讲读者需要的结论，再讲理由；简短不等于删掉影响判断的限制。原稿需研究核对时单列缺口，不用润色掩盖。
5. 再读一遍，检查是否增添或丢失含义、来源、条件与商业承诺。文件模式只改文字，代码、表格数据、链接目标和元数据保持原样。
6. 默认给最终改稿和必要的修改说明；用户只要正文时只给正文。需要文件就使用当前 WorkBuddy 文件能力保存副本，保留原稿。
