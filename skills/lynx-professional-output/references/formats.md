# 格式检查表

| 输出 | 最少应检查什么 | 交付应包含什么 |
| --- | --- | --- |
| Markdown/调研 | 引用支持结论、日期、层级、表格和链接；可公开内容边界 | 完整稿、引用与未知项 |
| Word/PDF | 实际渲染、字体、分页、表格跨页、裁切、页码与目录（适用时） | 正式文件和必要的可编辑源 |
| PPT | 文字已确认或制作已授权；逐页渲染、主线、可读性、图表、备注与时间估算 | 可编辑 PPT、备注和必要预览 |
| Excel/CSV | 编码、类型、单位、日期、缺失、重复、公式、关键结果复算与打开后显示 | 处理后文件、计算口径和原始数据引用 |
| 产品演示视频 | 实际成片、时长、比例/分辨率、画面、声音、字幕、版权来源与解码 | 成片、必要源工程和播放说明 |

默认最少满足真实用途；不是每个小任务都做完整出版审计。财务、法务、版权或平台正式签核沿用公司与客户既有责任，不以本包的自动检查代替。
