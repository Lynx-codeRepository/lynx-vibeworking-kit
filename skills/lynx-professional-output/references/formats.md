# 常用工作材料

客户方案：目的与业务问题、已确认现状、目标、每个步骤解决的问题、公司服务匹配、阶段成果、评价方式、资源/边界、下一步。不给未经批准的效果或报价承诺。

调研报告：决策摘要、方法与范围、事实与数据、解释/替代解释、建议、来源、缺口。客户/行业/公开数据研究先用调研技能获取证据。

周报/月报：完成什么及业务价值、可核实数字、主要问题/改进、下阶段计划、需要的资源/决策。自然表达，避免堆过程。

会议纪要：日期/参与者（来源明确）、共识与决定、讨论与提议、行动项（负责人/截止日期仅填已确认）、开放问题。听不清或身份未明注明，不擅自指定发言人。

格式：有 Word 工具按需求生成；没有则交可编辑 Markdown，明确格式。原材料不改。导出 PDF 可以作为阅读版，但源文件一起提供。专业/法律/财务判断涉及关键决策时标记需要对应负责人复核，不能借技能名称宣称资质。
