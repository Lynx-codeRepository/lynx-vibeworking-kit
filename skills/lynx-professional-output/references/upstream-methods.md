# 客户会议后的三种产出

用户上传录音转写、纪要或零散拜访笔记即可，不要求CRM、邮箱或会议平台连接。先核对材料覆盖的会议日期、客户、参与者与发言识别可靠性。

提取客户目标、现状、问题、要求/限制、提议、异议与承诺；承诺要能追溯到说话者或记录，期限和负责人没确认就留待确认。多次会议中冲突的信息保留变化时间，不能拼成单一结论。

面向客户的跟进草稿：确认共识、双方下一步、所需材料与待决定问题。面向团队的摘要：机会、风险、交付边界与行动项。面向任务管理的清单：事项、责任、期限、状态和原记录来源。按用户请求生成其中需要的产物，不强制每次输出三份。

涉及报价、效果、范围和排期时以已确认材料为准；原稿中的提议不变成正式承诺。本流程默认交付材料，是否发送按当前授权执行。
