# 把业务目标落到选题与执行

读 [内容与活动方法](references/content-method.md)，来源见 [改编记录](THIRD_PARTY_NOTICES.md)。公司与客户能力以本次已确认材料为准。

1. 读品牌材料、客户研究、过往内容和运营数据，确认目标、受众、期间、渠道、已有资产、预算和制作资源。没有预算不编金额，没有数据不编达成率。
2. 从受众的问题和决策阶段选择内容主题；每个主题连接可信的产品/服务事实、表达角度、支撑材料与下一步行动。主题数量按资源与业务需要决定。
3. 区分可通过检索找到的内容和适合分享传播的内容，匹配渠道；把同一母题改为各平台能使用的形式，避免机械复制文案。
4. 输出 [内容日历](templates/content-calendar.csv)：时间、受众问题、主题、证据/素材、渠道、形式、负责人、依赖、验收与指标。未确认负责人或日期保留待确认。
5. GEO选题重点检查问题是否真实、答案是否有事实依据、品牌/产品名称与来源是否一致；AI引用/提及、访问、转化分开评价，不保证排名或引用效果。
6. 按 [活动brief](templates/campaign-brief.md) 给执行顺序、资源缺口与复盘方法。优先级依据受众需求、业务价值、证据准备度和制作成本，不把模板中的频次当公司规定。
7. 交付可编辑计划、素材缺口与待确认项；可用 WorkBuddy 文件工具生成表格。发布内容、投放或修改账号按当前用户授权执行。
