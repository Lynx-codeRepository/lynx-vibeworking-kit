# 竞争分析的证据与比较

市场格局和针对一个客户的售前比较是两种任务。前者寻找参与者、定位与内容机会，后者围绕客户明确的决策条件比较。先确定本次问题，再决定调查哪些对象。

## 比较维度

业务对象、客户问题、价值主张、产品/服务、证据/案例、价格与条件、渠道/内容、近期变化、已知优势、未验证项。保持每个竞争者采用相同定义与采集日期；公开价格与报价、官方承诺与实际体验分开。

## 工作顺序

1. 记录对象和筛选理由，读官网关键页面与官方近期动态；用户给了名单就从该名单开展。
2. 收集证据、时间与链接，保留原文支撑。原始资料足以支撑时不要求付费SEO、流量服务或CRM连接。
3. 从同一维度形成矩阵，再分析定位、内容覆盖、价值证据与客户需求的差异。未找到证据不等于不存在。
4. 售前简报给清楚的比较、可证明的价值与要问客户的问题；赢单/失单原因只从用户真实记录提炼，不假设有访谈或销售数据。
5. 每项建议写影响、证据、下一步验证与资源；不凭星数、宣传词或未经验证份额给行业排名。
