# 用可比较的事实支持判断

读取 [竞争分析方法](references/competitive-method.md)。来源见 [改编记录](THIRD_PARTY_NOTICES.md)。

1. 明确本次决定、行业边界、地区/期间、对比对象与灵熙或客户的服务范围。用户给了名单就使用该名单；需要发现竞品时说明选择依据。
2. 用 WorkBuddy 搜索和网页读取搜集官网产品页、公开价格、案例、官方内容渠道、近期发布及可核对评价。同类信息按相同日期和口径比较。
3. 填写 [证据矩阵](templates/competitive-matrix.csv)：客户对象、承诺价值、产品/服务、渠道/内容、价格范围、证据、未知项。未公开的数据写不可获得，不估造流量或份额。
4. 识别竞争者强调的价值、客户真实需求覆盖情况、证据支持的差异、未覆盖的内容议题。把事实与机会假设分开；不把未找到内容写成对方没有能力。
5. 给每项建议写业务意义、证据、下一步验证与优先级。售前对比只使用已确认公司能力，避免贬低竞争者或承诺无法证明的优势。
6. 交付 [竞争简报](templates/competitive-brief.md)、比较表、来源清单和客户沟通问题。关键比较和来源逐条复核。

不要求 CRM、数据仓库或外部 API Key。联网不可用时按附件完成对比，并注明未联网核实。
