# 公司业务与写作基线

对外名称：灵熙智能。服务场景包括品牌数字资产、内容运营、GEO/AI 搜索可见度、媒介内容分发、客户方案及运营复盘；实际提供哪些服务，以本次已确认材料为准。

公司项目类型只帮助识别业务场景，不意味着员工要开发这些系统。方案围绕客户业务问题、价值、工作流程、阶段成果和验收方式组织。

- 客户方案：先提炼主题和逐页文案；用户确认文案后生成 PPT。用户已明确授权完整制作时直接完成。客户版使用业务语言，少堆技术名词；不未经批准写竞品贬损、收入/效果承诺。最后一页致谢。来源、限制和细节可放讲稿/附表。
- 管理汇报：成果与价值 → 问题及改进 → 下阶段计划 → 资源/待决策。讲话稿自然简明，数字有依据。
- 调研：公开资料形成的推断不等于客户需求；会议共识、提议和开放问题分开。案例、报价、排期和产能只用确认材料。
- 数据：注明指标、单位、时间、分母和来源；AI 引用/提及、网站访问与真实转化分别追踪。
- 文件：默认中文，可编辑；原始资料不改动，保存来源与计算明细。真实客户资料不纳入 Kit 仓库。
