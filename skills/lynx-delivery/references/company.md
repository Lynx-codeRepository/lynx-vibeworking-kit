# 公司项目基线

核对日期：2026-10-08。组织：Lynx-codeRepository。此文件是 Kit 的初版项目地图，不能代替目标项目当前代码、客户合同和负责人决定。

## 业务与协作方式

- 围绕品牌数字资产、内容生产、审核协作、GEO/AI 营销、媒介运营、企业工作台、官网、小程序和专业交付材料提供支持。
- 业务定义结果与事实，运营核对内容与流程，研发负责架构与可运行实现；小团队成员可以承担多个角色。新人通过自然语言描述目标，AI 承担专业拆解、执行和证据整理。
- 复用已有任务、项目与工作项；需要 GitHub 协作时采用任务 → 短分支 → PR → 适用检查 → 一名非作者审查 → 合并 → 发布验证。Kit 不自动创建通知或修改组织权限。
- 不把示例、Mock、AI 推断、演示数据、历史记录当作当前真实客户事实。产品参数、版权、渠道规则、费用和市场信息使用前核对来源与日期。
- 同一产品优先共享核心和配置化差异，是否独立部署或独立数据库按项目与客户合同决定。

## 公司交付默认

专业、克制、清楚；让客户和新人知道下一步怎么用。资料默认 Markdown，指定 Word/PPT/PDF/表格时按该格式交付。PPT 先形成可审阅文字；用户已有内容确认或直接授权制作时继续。AI 成果应可追溯事实、数据、版本和实际验证环境。

项目现有工具和技能优先。Kit 不打包模型账号、API Key、员工密码、客户原文件、第三方技能源码或浏览器登录态。远端仓库调研仅是代码/文档证据，不等于已访问客户业务环境。
