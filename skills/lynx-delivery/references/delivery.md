# 按任务进入

- [客户方案与 PPT](packs/proposal-ppt.md)：讲清问题、业务价值、范围、流程和成果。
- [客户与竞品调研](packs/client-research.md)：给出证据与第一次沟通要验证的问题。
- [行业调研](packs/industry-research.md)：边界、趋势、参与者、机会与风险。
- [公开数据调研](packs/data-research.md)：找到符合口径的数据，报告缺口。
- [运营数据分析](packs/data-analysis.md)：先检查质量和指标，再计算与解释。
- [报告与汇报](packs/report-writing.md)：事实整理、结论、行动与责任。

统一节奏：明确任务 → 核对材料/工具 → 证据/口径 → 专业处理 → 可编辑成果 → 检查与交接。每一步解决一个具体业务问题，员工只需提供材料和判断关键选择。
