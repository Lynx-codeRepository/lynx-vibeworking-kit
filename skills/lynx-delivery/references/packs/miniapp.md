# 小程序与移动业务

适用：现有 uni-app/Vue 或用户明确指定的平台项目。必要输入：业务目标、目标平台、当前仓库、页面路径、角色与接口；AppID、包名和审核账号只核对配置位置，不复制凭据。

## 方法

1. 读 App、pages、manifest、分包、组件、登录和请求封装，核对真实开发工具与目标基础库。沿用现有栈，不未经要求升级框架或移动全部页面。
2. 先完成入口 → 页面 → 数据 → 用户操作 → 成功/异常反馈。处理安全区、触控、键盘遮挡、网络失败、登录过期、重复提交与页面返回。
3. 敏感权限按平台和业务需要申请，拒绝授权时提供可继续使用的降级体验；不用空壳页面伪装能力。服务端验证身份和对象权限。
4. 静态资源、分包体积、隐私说明、接口域名和发布材料按当前平台要求核验，不能凭旧文档认定符合提审要求。

## 验收与恢复

在目标平台开发工具走主流程，改动涉及平台或设备行为时安排真机验证；H5 通过不能替代微信/其他平台，也不能替代实体手机。记录基础库/工具版本、机型和网络场景。

开发者工具或真机缺失时完成代码与可验证部分并给出待测清单。构建、提审与发布是独立状态；不得声称已审核通过。交付操作路径、验证证据、发布材料与缺失条件。
