# GEO 诊断与品牌内容

适用：AI 能见度诊断、品牌文章、内容策略、信源分析和复测。必要输入：品牌/产品、目标问题、人群、事实资料、渠道、诊断周期和输出格式；发布账号与预算只在实际需要时核对。

## 方法

1. 建立事实与来源账本：结论、来源 URL/文件、获取日期、支持内容、可信度与未知项。型号、参数、价格、认证和竞品对比需实时核对，不从旧稿或模型记忆直接认定。
2. 诊断固定问题集、模型/平台、采样日期、地区/账号条件和次数；区分品牌提及、引用信源、位次、回答质量。保存样本与计算口径，说明平台波动和样本量。
3. 写作从读者问题出发，用有来源的事实、可理解的场景、清楚的结构与行动建议。不得编造实测、专家身份、销售排名、证书、用户评价或绝对优势。
4. 内容 → 审核 → 授权渠道投放 → 回链/截图 → 引用监测 → 修改复测形成闭环。不能承诺“包收录/必引用/保证增长”；对照采样不稳定时不能断言因果。
5. 开发报告页面时强调分数、样本、证据与下一步；手机上顺畅阅读，颜色表达状态而非装饰。

## 验收与恢复

事实逐项可追溯、指标能从样本复算、引用确实支持结论、正文符合渠道和客户口径。发布前给出实际稿件、目标账号/渠道与预算；授权范围充分时继续，缺失时完成草稿与 payload。

缺少真实模型访问时交付问题集、采样设计与分析模板，明确尚无真实诊断结果。内容发布、回链记录与业务增长分别验证。品牌专用技能存在时核对其证据和当前范围后复用，不把本包当作产品事实库。
