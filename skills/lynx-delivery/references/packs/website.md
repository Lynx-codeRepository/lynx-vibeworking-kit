# 官网与业务页面

适用：官网、产品页、落地页、后台页面、表单与移动体验。必要输入：用户目标、品牌/产品事实、参考页面、现有仓库或新建范围；缺少素材时使用明确的占位，不能伪造客户 Logo、案例或联系方式。

## 方法

1. 确定主要用户任务和主动作，读当前路由、设计约定、组件与数据接口。新网站先给出必要页面和信息层级；现有页面复用交互与视觉体系。
2. 把用户流程串通：入口 → 查阅信息 → 执行动作 → 成功/失败反馈。表单保留失败输入，提交中有可见状态，防止重复提交。
3. 内容先保证事实与可读性，再处理留白、字号、色彩、图像和动效。手机导航、长表格和触控需要适配；不要把桌面压缩成手机。
4. SEO/AI 可见性按任务核对语义标题、元数据、规范 URL、抓取规则与实际可访问页面，不能保证排名或引用。

## 验收与恢复

在真实本地页面走主动作，检查桌面与 390px 左右窄屏、键盘焦点、溢出、加载/空/失败状态。针对改动运行相关构建和测试；避免在正在运行的开发目录执行会破坏缓存的构建。

浏览器能力缺失时用可用检查生成结果并明确视觉未验证，不能把截图概念稿当作网页已完成。交付可打开预览、相关文件、验证记录和上线前缺口；正式发布按当前授权执行。
