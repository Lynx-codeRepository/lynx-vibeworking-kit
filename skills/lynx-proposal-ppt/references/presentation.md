# 客户方案与可编辑演示

先确定文件是客户提案、单页方案还是管理汇报；使用用户提供的模板和材料，不从模型记忆补案例或效果。客户已有的问题、已确认能力和下一步决定构成内容主线。

## 客户材料流水线

为每项主张记录材料来源、适用对象与条件。把客户问题映射到方案步骤，再映射到阶段产出、负责人/资源和验收方式。客户案例与客户本人的成果分开；无法获得的数值、案例或logo写待确认。

每页只表达一个主结论，标题表达结论，正文给证据。讲清业务收益和实际做法，技术选型在帮助读者做决定时展开。来源、统计口径与假设放图下注、讲稿或附表；影响判断的限制不能被隐藏。

## 生成与检查

用当前 WorkBuddy 的PPT能力生成可编辑文件，已有品牌模板优先。文字、表格、图表保持原生编辑；配图可以是图片，但不把整页截图称为可编辑方案。没有工具时交逐页文案和材料清单，不要求员工安装软件或填写密钥。

逐页查看标题、换行、中文字体、对齐、溢出、单位、图表颜色与讲稿；抽查可编辑性。核对每个案例、数字、排期和预算是否来自认可材料。末页给已确认下一步和致谢。

根据 create-an-asset 与 marketing-plan 改编，去除平台专属产物、CRM和连接器前提。来源与许可见 [改编记录](../THIRD_PARTY_NOTICES.md)。
