# 做客户能理解、员工能讲的方案

先读 [客户方案方法](references/presentation.md)，来源与改编见 [改编记录](THIRD_PARTY_NOTICES.md)。公司名称用灵熙智能，服务范围以已确认资料为准。

1. 核对汇报对象、要促成的决定、客户问题、时长/页数与品牌模板。资料已经明确时直接推进。
2. 从客户材料、会议记录、服务说明与已获准案例建立证据表。每项效果、预算、排期与案例均有依据；没有的数据写待确认，不补成销售承诺。
3. 将内容组织为客户问题 → 判断依据 → 目标与价值 → 工作流程与阶段交付 → 成效评价 → 资源/范围/下一步。每页标题表达一个主结论，正文支撑它。
4. 用 [逐页文案模板](templates/slide-outline.md) 整理内容。用户只授权文案时先给文案；已授权整套制作时直接生成并检查，不逐页索要确认。
5. 使用当前 WorkBuddy 演示/文件工具生成原生可编辑 .pptx；保留文本、表格和图表的编辑性。没有生成工具时交逐页文案，明确正式 PPT 未生成，不要求员工安装环境。
6. 逐页打开或渲染检查中文字体、文字溢出、对齐、图表单位、来源和讲稿一致；抽查可编辑性。没有视觉检查工具时记录未检查的范围。
7. 交付 .pptx、必要的来源/支撑表和检查结果。客户版少堆技术术语，末页致谢；关键限制不能藏在极小字里。
