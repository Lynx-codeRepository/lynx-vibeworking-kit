# 数据探索、解释与交付前复核

先了解一行数据代表的对象和时间粒度，再选择分组和指标。字段名称不是指标定义；渠道、客户、作品、账号等标识字段不当作数值求和。用户只交表格即可，用 WorkBuddy 当前的表格与文件能力处理。

## 探索

记录工作表、行数、字段类型、期间、单位、空值、重复、非有限数值和异常范围。检查日期覆盖与样本选择；空值、零、未发生、无法读取分别处理。公式缓存是否最新需要重算证据，不能靠读取文件证明。

明确每个指标的分子、分母、去重键、筛选和转换；金额/数量保留单位，不默认转换币种。分组后合并比率时使用总分子/总分母；数据关联先检查键的唯一性和关联后的行数，避免一对多重复放大结果。

## 分析与图表

问题决定分析方法：比较用一致口径，趋势用一致时间粒度，排名说明样本范围。找异常时核实业务原因；样本偏差、遗漏变量和数据滞后写进结论限制。图表选择服务于问题：比较看条形，趋势看折线，关系看散点；轴、单位、期间和样本清楚，不能用截断坐标夸大差异。

## 交付前复核

- 明细和汇总能对账，过滤、去重、关联方法可复现。
- 独立核算至少一项关键指标，检查平均数、加权数、比率和分母。
- 图表与正文一致，百分点与相对变化区分，相关与原因区分。
- 每个建议对应数据证据与业务含义；置信程度用理由说明，不自造统一置信分数。
- 交可编辑明细、分析报告与检查记录；无数据的结论明确留待验证。
