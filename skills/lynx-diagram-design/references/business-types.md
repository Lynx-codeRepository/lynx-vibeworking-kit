# 按办公任务选图

| 要讲清楚的事情 | 优先图型 | 读取方法 |
|---|---|---|
| 客户服务、内容审批或发布步骤 | 流程/过程图 | [流程图](type-flowchart.md)、[过程图](type-process.md) |
| 业务、运营、研发各自负责什么 | 泳道图 | [泳道](type-swimlane.md) |
| 客户接触点、体验与服务后台 | 客户旅程/服务蓝图 | [客户旅程](type-journey.md)、[服务蓝图](type-service-blueprint.md) |
| 项目里程碑、活动排期 | 时间线/甘特图 | [时间线](type-timeline.md)、[甘特](type-gantt.md) |
| 竞品定位、优先级、原因分析 | 象限/鱼骨图 | [象限](type-quadrant.md)、[鱼骨](type-fishbone.md) |
| 团队归属、任务分工 | 组织图/树 | [组织图](type-org-chart.md)、[树](type-tree.md) |
| 内容生产与GEO运营的模块关系 | 架构/数据流 | [架构](type-architecture.md)、[数据流](type-data-flow.md) |
| 渠道对比、趋势、预算增减 | 柱状/折线/瀑布 | [柱状](type-bar.md)、[折线](type-line.md)、[瀑布](type-waterfall.md) |
| 有同一口径的转化或流量去向 | 漏斗/桑基 | [漏斗](type-pyramid.md)、[桑基](type-sankey.md) |
| 多维评分、分布、相关关系 | 雷达/热力/散点 | [雷达](type-radar.md)、[热力](type-heatmap.md)、[散点](type-scatter.md) |

资料不足时先做关系或数据清单；不为做图而编数据。趋势必须按真实时间排列，柱状图保留单位/期间/分母，象限坐标有定义，多维评分要有同一尺度和评分依据。
