# 工作方式

员工选任务 → 上传对应技能 → 交目标和材料 → AI研究/计算/成稿 → 可编辑成果与证据 → 员工核对。

九个独立技能覆盖客户调查、竞品/行业比较、方案PPT、数据分析、内容计划、汇报纪要、文字润色、图表可视化和任务选择。每包内部引用完整，按需启用；任务助手按名称引导其他技能，没有其他技能时也可使用已有材料和工具开展工作。

办公版以Markdown工作方法、CSV/Markdown和静态HTML/SVG模板组织，使用WorkBuddy当前搜索、附件与Office能力。没有运行依赖、连接器清单或外部账号配置。专业方法来自固定版本的开源技能并加入灵熙业务与证据要求，见 [来源目录](github-resources.md)。

维护者完整包保留CLI、PPT和数据脚本；这些脚本不进入员工技能ZIP。CLI默认生成供复制的WORKBUDDY-START.md，不声称WorkBuddy自动读取隐藏目录。Codex/Cursor作为维护入口保留。
