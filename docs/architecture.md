# 工作方式

员工 → WorkBuddy 导入技能 → 交目标与材料 → AI 核对资料 → 执行研究/计算/方案 → 可编辑成果 → 来源与检查 → 员工审阅。

1. **明确任务**：谁看、为哪个决策服务、截止时间、已确认资料与业务范围。解决目标不清和输出错位。
2. **证据准备**：附件读取、公开检索、来源记账、数据质量和口径。解决凭空判断、数字混用。
3. **专业工作**：对应技能按任务执行；已有工具优先，GitHub 资源按目录接入。解决零基础员工不会拆专业步骤。
4. **产出文件**：方案/PPT、研究报告/表格、分析明细/图表、行动清单。解决只有聊天结论不能使用。
5. **交付检查**：来源、数字、文件编辑性、PPT 排版、计算复核。解决有文件但结果不可靠。

五个独立技能可在 WorkBuddy 同时启用。路由技能按名称指引其他技能；它们不是必须互相读取的外部文件，单包内部引用完整。

技术选择：技能使用 Markdown 与 WorkBuddy 官方元数据；模板为 Markdown/CSV/JSON；CSV 检查用 Python 标准库，Excel 用可选 openpyxl；PPT 用 PptxGenJS 原生文本、表格和图表。不会将截图拼接当作可编辑 PPT。联网搜索优先使用当前 WorkBuddy 能力；高级研究服务需要维护者配置。

维护者可用 CLI 为每个任务建立 `.lynx-kit` 记录。默认生成 WORKBUDDY-START.md，供员工复制指令，不声称该文件由 WorkBuddy 自动加载。保留 Codex/Cursor 兼容作为维护选项。
