# Lynx VibeCoding Kit

**给灵熙公司的业务、运营和研发新人：用自然语言提出任务，让 AI 按公司的项目方式持续做到可用、可验证、可交接。**

不需要先学会写技术方案。你告诉 AI 想得到什么、给谁用、有哪些资料，Kit 提供公司背景、专业任务方法、验收要求和可复用的项目入口。

👉 **第一次使用，打开 [新人开始](START-HERE.md)。**

## 直接复制这段给 AI

```text
请使用 Lynx VibeCoding Kit 帮我完成公司的任务。
Kit 仓库：https://github.com/Lynx-codeRepository/lynx-vibecoding-kit
请先获取并读取 START-HERE.md、AGENTS.md 和对应任务技能。
我的目标是：[用一句话说想得到的结果]
给谁用：[客户、部门或使用者]
现有项目或资料：[文件夹、仓库链接或已提供的文件]
先核对现状，沿用项目已有架构；必要时把 Kit 接入指定工作区。
只问影响范围、事实、授权或验收的关键问题，其余持续推进。
最后给我可以使用的成果、使用方式、实际验证结果和未覆盖范围。
```

仓库是私有的，使用者需要组织仓库访问权和能操作本地文件的 AI 工具。仅能聊天或无法读取私有仓库时，请负责人提供下载包；解压后让 AI 读取其中的 START-HERE.md。Kit 自身无需 API Key，也没有后台收费服务；所用 AI、制作工具或第三方服务按公司已有账号和授权提供。

## 八类公司任务

| 任务 | 可以这样说 | 交付关注点 |
| --- | --- | --- |
| 官网与业务页面 | “帮我把产品页做完整，手机也能用” | 可用预览、真实主路径、视觉与表单 |
| 品牌资产与审核 | “这条资产提审卡住了，修到能审核和入库” | 业务闭环、角色、版本与文件一致 |
| 视频审核与媒体 | “在现有工作台增加多版本对比” | 帧定位、意见版本、同步与受控分享 |
| GEO 与品牌内容 | “给这个产品做有证据的诊断和文章” | 事实来源、采样、稿件与复测 |
| 内容工厂与媒介 | “修复归档投放与积分流水” | 事务、权限、OSS 与幂等 |
| 小程序与移动业务 | “做这个业务表单并准备提审” | 平台行为、设备、接口与提审材料 |
| 内部工作台与自动化 | “做项目进度看板并自动汇总” | 真实数据、权限、运行与撤销 |
| 调研、文档、数据与演示 | “用这些资料做客户方案和汇报” | 正式文件、事实/计算与渲染检查 |

公司基线已按当前组织仓库核对，见 [来源与范围](docs/sources.md)。已有项目的当前代码与规则优先。不同系统继续使用自己的技术架构，Kit 提供任务工作区与方法，不强制生成一个统一的应用骨架。

## 包里有什么

- 三个可复用技能：公司任务交付、页面验收、专业材料交付；主技能按需加载八类专业任务包。
- 创建新任务工作区或接入旧项目的安装器；预览改动、不覆盖已有文件、不改个人全局配置。
- Codex、Claude Code、Cursor 项目入口与规则文件。
- 任务、验收、证据与接力模板，及 GitHub Issue/PR 和自动检查。
- 不依赖第三方库的本地工具，可检查环境可调用性、成果文件和证据记录。

## AI 与维护者使用

Node.js 22+ 即可执行，无需先安装本 Kit 依赖。任务类型见 `catalog`。

```bash
node bin/lynx-kit.mjs catalog
node bin/lynx-kit.mjs init --directory ../customer-website --type website --name "客户官网" --goal "完成产品介绍和联系表单" --tool all
node bin/lynx-kit.mjs attach --directory ../existing-project --type dam --name "审核流程修复" --goal "让指定资产能从提审到入库和下载" --dry-run
node bin/lynx-kit.mjs doctor --type website
npm run check
```

安装后在目标项目读取 `.lynx-kit/START.md`。`init` 只写新目录/空目录，`attach` 用于现有项目；已有 Kit 或同名技能时停止，不做隐式升级。接入旧项目时保留已有 AGENTS/CLAUDE 文件，并提示在 AI 会话显式读取入口。

**能力与边界：** Kit 提供流程与方法，仍需要 AI、本地工具、项目资料与相应权限。生成工作区不代表完成业务系统；check 只核对文件与证据记录，不替代真实测试、上线或客户验收。初版安装与结构已自动验证，真实员工跨工具使用仍需试用反馈。
